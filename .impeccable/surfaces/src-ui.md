# Surface Brief: DeltaCheck Web Workspace (`src/ui`)

- **Visitor Mode:** Operate (interactive verification workbench for inspecting temporal-memory recall, search query fan-out, and source-cited diffs)
- **Primary Audience:** Developers inspecting temporal RAG runs and personal researchers revisiting earlier notes across days.
- **Core Action:** Anchor a follow-up prompt to a calendar reference, inspect recalled baseline + live queries + cited diffs, and inspect full sources in the modal.

## Direction contract

- **THESIS:** Replace soft dark-gray AI chat bubbles and orange pills with sharp, unpadded optical-spectroscopy ash plates registered to an off-centre calibrated date rail where 1px emission hairlines encode temporal provenance and verification state.
- **OWN-WORLD:** Emission Line Continuum (`operate-c-emission-line-rail`) — procedural charcoal ground (`#101214`), deep rail (`#14171a`), ash specimen plates (`#181b1e`), warm bone ink (`#ebe8df`) and muted ash (`#9c988f`), sodium-gold doubled marker (`#ffcf48`) for active thread selection and anchored dates, cyan (`#4cc9f0`) for live search queries, emerald (`#5ec27e`) for verified live status, sharp `2px` radii, and `Work Sans` + `Spline Sans Mono`.
- **STORY:** A user immediately sees saved threads hanging off one calibrated rail (`-2d`, `-8d`), anchors a question by date, watches Stage 1–2 queries resolve as spectral ticks, reads source-cited differences against the recalled baseline, and audits every query and snippet without leaving keyboard focus.
